# case006_byte_array_transformation (maintainer notes)

This directory is maintainer-only and is never shipped to a solving agent. It holds the
source tree, build/verify/grade scripts, dist output, build metadata and the private oracle.

The browser page is a local archive intake manifest. It accepts a batch key, file name,
description, category, profile mode, codec, shard, a normalization flag and a byte-transform
consent state, then emits one observable `console.log` object with action `byte.pipe.commit`
and a deterministic `byte_array_payload` field after the scan / preview / consent / seal /
final commit flow is completed.

## Layout

- `src/` — module source. The entry is `src/z0/a0.js`; the byte-array constructor lives in
  `src/z0/k7/q3/t9.js` (`constructByteArrayPayload`, reached through the exported `u`).
- `scripts/build.mjs` — rolls up `src/z0/a0.js`, obfuscates it (fixed `seed`), writes
  `dist/`, syncs the public capture into `agent_visible/captures/`, then runs
  `gen_oracle_spans.mjs` and refreshes `build_meta.hidden.json`.
- `scripts/gen_oracle_spans.mjs` — re-derives every `captured_span` (offsets, lines, hashes)
  for each `oracle.hidden.json` row from its `answer_function` in the captured bundle.
- `scripts/verify.mjs` — structural and runtime checks (Playwright). Does not grade agent
  answers.
- `scripts/grade_submission.mjs` — maps an agent submission to a score against the oracle.
- `oracle.hidden.json` — private gold standard (anchor + role oracle, dual-track
  `answer_function`/`source_function`).
- `build_meta.hidden.json` — task contract, difficulty analysis and a mirror of the anchor
  identity. Regenerated by the build.

## Commands

```bash
npm ci
npm run build    # regenerate dist + captures + oracle spans + build_meta
npm run verify   # structural + runtime verification
npm run grade -- <submission.json>
```

## Reproducibility

The obfuscator runs with a fixed `seed`, and `devDependencies` are pinned with a committed
`package-lock.json`, so a clean `npm ci && npm run build` reproduces the captured bundle
byte-for-byte and the oracle spans remain valid.
