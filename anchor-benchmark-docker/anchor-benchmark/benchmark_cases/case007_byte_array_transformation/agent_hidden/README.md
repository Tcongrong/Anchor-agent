# case007_byte_array_transformation - maintainer notes (agent_hidden)

This directory is private to maintainers, graders and CI. It must never be
packaged for a solving agent (only `../agent_visible/` is).

## Layout

- `src/host/`: page, styles and favicon.
- `src/z0/`: markdown preview behavior chain, typed-array transformation
  logic (anchor and nested helpers), staging/queue modules, distractor pool
  (`x/`), and vendor noise (`v/`).
- `src/z0/k7/q3/t9.js`: typed-array anchor module (transform, materialize,
  encode helpers) exported through factory `u(config)`.
- `scripts/`: build, static serve, verify, oracle-span generation and grading.
- `dist/`: built deliverable page (regenerated by `npm run build`).
- `build_meta.hidden.json`: public task contract, candidate scope and difficulty
  analysis (no answer-bearing material).
- `oracle.hidden.json`: private gold standard (primary anchor + role oracle).

## Pipeline

`npm run build` runs: source build (Rollup, single ES bundle) -> obfuscation
(deterministic, fixed `seed`) -> `dist/` scan -> capture sync into
`../agent_visible/captures/` (assets directory cleared before copy) ->
`gen_oracle_spans.mjs` (recomputes every `captured_span`/hash/`answer_function`
from the freshly built captures) -> `build_meta` refresh. Because the build is
seeded and deterministic, two clean builds produce byte-identical bundles and
identical oracle spans.

## Standard interaction (matches `agent_visible/task.json` and `verify.mjs`)

1. Type into `#markdownInput`:

   ```markdown
   # Array Plan

   - stage benchmark
   - transform output

   > verify typed payload
   ```

2. Select `reader` in `#previewMode`.
3. Select `header-biased` in `#arrayProfile`.
4. Set `#byteWindow` to `21`.
5. Check `#autoToc` and `#scrambleWhitespace`.
6. Click `#stageButton`, then `#transformButton`.

Expected console object:

```js
{ action: "markdown.preview", status: "rendered", mode: "reader", typed_array_payload: "ta_..." }
```

## Grading

```bash
node scripts/grade_submission.mjs <submission.json>
```

Scores the submission against `oracle.hidden.json` by re-cutting the captured
bundle at the submitted offsets and mapping the span to a unique role row.
