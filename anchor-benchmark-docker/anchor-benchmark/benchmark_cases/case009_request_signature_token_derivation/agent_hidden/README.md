# case009_request_signature_token_derivation -- maintainer notes (agent_hidden)

This directory holds the private maintainer material for the case. The participating agent never sees it;
it only sees `../agent_visible/` (`task.json` + `captures/`).

## What the case is
A local two-step reservation request signer. The page collects a request reference, time window and
service tier, requires a replay-protection guard, and on Arm then Sign prints an object to the browser
console under action `reservation.sign`. The observable target is that object's `req_sig` field: a
deterministic `sig_` signature token derived from the request fields, run-time transit state and shadow
lanes via a keyed `Math.imul`/xor/rotate digest (anchored by the constant `0x27d4eb2d`).

## Anchor (private)
- source_function `r`: the inner signing closure returned by the exported factory `u(config)` in
  `src/z0/k7/q3/t9.js`; the live instance is the one bound to slot 23.
- answer_function is the obfuscated bundle identifier (e.g. `_0x4244cc`); it is regenerated by
  `scripts/gen_oracle_spans.mjs` after every build, so do not hard-code it.
- Grading is by `captured_span` (offset/hash + complete enclosing function); `function_name` is a secondary
  key. `source_function` is a maintainer mapping only and is never the required agent answer.

## Layout
- `src/`: source (host page + `z0/**` business / decoy / vendor modules). In-task content; line-count
  floors apply here only.
- `scripts/build.mjs`: rollup then javascript-obfuscator (fixed `seed`, pinned deps + lockfile, byte
  reproducible). Writes `dist/`, copies the bundle + page into `../agent_visible/captures/`, refreshes the
  capture manifest, then runs `gen_oracle_spans.mjs`.
- `scripts/gen_oracle_spans.mjs`: re-derives every `oracle.hidden.json` `captured_span` against the current
  captured bundle (anchor by `0x27d4eb2d`; the rest by AST call-graph), writes `answer_function` +
  `source_function`, mirrors `primary_anchor` into `build_meta`, and self-audits.
- `scripts/verify.mjs`: case structure + runtime checks (drives the page in Chromium, confirms the
  `reservation.sign` / `req_sig` console object, sensitivity and decoy boundaries). It does NOT score
  agent answers.
- `scripts/grade_submission.mjs`: scores an agent submission against `oracle.hidden.json`.
- `oracle.hidden.json`: private gold standard (`primary_anchor` + `role_oracle`, dual-track names).
- `build_meta.hidden.json`: task contract, difficulty and analysis (regenerated by the build).

## Rebuild loop
```
cd agent_hidden
npm ci            # pinned deps from package-lock.json
npm run build     # dist -> sync captures -> regenerate oracle spans
npm run verify    # runtime + structure checks
npm run grade -- <submission.json>   # score an answer
```
Any change to `src/`, deps, the seed or the layout changes the obfuscated bundle byte-for-byte, so the
build must be re-run so `captures/` and `oracle.hidden.json` stay in sync (the build does this automatically).
