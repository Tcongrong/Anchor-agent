# Maintainer materials

This directory contains private benchmark maintenance files for `case003_browser_fingerprint`.

- `src/` contains the source page and browser logic.
- `dist/` is generated by `npm run build`.
- `scripts/` contains build, verify, serve, oracle regeneration and grading utilities.
- `oracle.hidden.json` and `build_meta.hidden.json` are maintainer-only metadata.

Run `npm run build` after source or obfuscation changes, then run `npm run verify`.
