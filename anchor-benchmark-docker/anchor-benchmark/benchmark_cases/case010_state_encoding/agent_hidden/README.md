# case010_state_encoding — maintainer / grader material

Not visible to benchmark agents. Contains the source, build/verify tooling, and
the private oracle.

| File / dir | Purpose |
|---|---|
| `src/` | Page host + `z0/**` business, chain, decoy and vendor modules. The anchor lives in `src/z0/k7/q3/t9.js` (`makeReducer` returns the reducer closure `r`). |
| `scripts/build.mjs` | rollup → javascript-obfuscator (mangled, `renameGlobals:false`, fixed seed 1010). Emits `dist/assets/media.app.bundle.js`, syncs it into `agent_visible/captures/`, then runs `gen_oracle_spans.mjs`. |
| `scripts/gen_oracle_spans.mjs` | Recomputes every `role_oracle` `captured_span` + `answer_function` from the frozen captures bundle. The anchor closure is resolved structurally (the function expression returned by `makeReducer`). |
| `scripts/verify.mjs` | Serves `dist/` and drives the page with Playwright; checks the runtime observable, sensitivity and leakage boundaries. |
| `scripts/grade_submission.mjs` | Scores an agent submission against `oracle.hidden.json` by captured span. |
| `scripts/serve.mjs` | Local static server for manual inspection (`PORT`, default 4211). |
| `oracle.hidden.json` | Private gold standard: `primary_anchor` + `role_oracle` (dual-track `answer_function` / `source_function`). |
| `build_meta.hidden.json` | Task contract, difficulty analysis and the `primary_anchor` mirror (regenerated by the build). |

Standard loop:

```bash
cd agent_hidden
npm install      # pinned devDependencies
npm run build    # build → sync captures → regenerate oracle spans
npm run verify   # Playwright runtime + structural checks
```
